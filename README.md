# statistic-site — LVPD Private

Render-ready private archive for investigations, photos, helper configs and files.

Registration is optional. Guests can view public materials. New accounts start as `viewer`.
Roles: `admin`, `investigator`, `editor`, `viewer`.

Set `ADMIN_USERNAME` and `ADMIN_PASSWORD` in Render. The first matching account is created as admin.

Deploy with `render.yaml` or manually: Build `npm install`, Start `npm start`.
